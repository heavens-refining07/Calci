# Calculator Web App

A responsive calculator built with plain HTML, CSS and JavaScript.

## Features

- Addition, subtraction, multiplication and division
- Decimal calculations
- AC and DEL buttons
- Keyboard support
- Responsive mobile-friendly UI
- No external dependencies
- Ready to deploy on Render as a static site

## Run locally

Open `index.html` directly in a browser, or use any simple static server.

## Deploy on Render

1. Create a GitHub repository and upload these files.
2. In Render, create a **Static Site**.
3. Connect your GitHub repository.
4. Build command: leave empty.
5. Publish directory: `.`
6. Deploy.

No Node.js or database is required.
